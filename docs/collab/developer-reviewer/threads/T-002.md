## 5. Review-01（2026-11-24）— **FAIL**

- 范围：`d38f282..03a0717` 的实现；报告 `docs/collab/qc-reports/PAY-SETTLE-01-Review-01.md`。
- 结论：实现级 **FAIL**，6 个阻断项 P-01…P-06：
  1. TCC 补偿绕过组级准入（退款后仍可发货）；
  2. 缺货组仍可发货（缺货案件不撤 permit，AuthorizeShipment 不查缺货/行就绪）；
  3. 零元单退款/缺货路径被 `captured>0` 阻断；
  4. 历史 `PAID` 无 `settlement_payment_no` 的退款被阻断；
  5. commitment 无 `RELEASED` 路径；
  6. 组额度未按责任过滤运费。
- 本线程保持 `OPEN`；修复并重跑有范围审查前不得关闭，更不构成 Release PASS。
