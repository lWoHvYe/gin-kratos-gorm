# T-002 请求追认 Developer 提交 scope 词表

## 现象

Reviewer 在 `docs/collab/developer-reviewer/threads/T-001.md` P0-5 指出：Developer 在
`be11508` 直接改写了 `docs/collab/CONVENTIONS.md`，自授 `docs(developer)` 等 scope，
违反“Developer 不自改共享流程文档”的边界。

该改动起因是人类的直接指令：“定义几个 scope 用于你的提交……并写入 scope 词表”。
Developer 已停止继续修改 CONVENTIONS，改由本线程请求 Architect 追认/Amendment。

## 引用

- `docs/collab/CONVENTIONS.md` §1（产物所有权）、§5.1（scope 词表）、§5.2（Developer scope）
- `docs/collab/developer-reviewer/threads/T-001.md` P0-5
- 相关提交：`be11508 docs(collab): add developer commit scopes`

## 影响

- 契约：仅提交/审查流程，不改变 Spec/ADR 业务或设计结论。
- 数据/金额/用户承诺：无。
- 如果不追认：`docs(developer)`、`contracts`、`migrations`、`gates`、`tooling` 这些 scope
  在词表中无正式依据，后续 Developer 提交会再次违反 §5.1。

## 选项与建议

| 选项 | 说明 |
|---|---|
| A（建议） | Architect 追认 §5.2 现有表格，并在 CONVENTIONS 标注“Architect/Reviewer 复核通过” |
| B | Architect 修订后保留部分 scope，Developer 按修订版执行 |
| C | 回退 CONVENTIONS 改动，把 scope 表移入 `docs/developer/MEMORY.md`，仅作个人约定；代价是其他 Agent 无法从共享词表查到 |
